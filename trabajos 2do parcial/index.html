Portafolio de Prácticas

MÓDULO 01

Inicio y Fundamentos

Conjunto de prácticas orientadas a comprender la sintaxis inicial de JavaScript, la declaración de variables, la estructuración de documentos y los primeros entornos de prueba y despliegue de mensajes en consola o pantalla.

  • Aprendiendo JS
  • Datos
  • Laboratorio
  • Mostrar Mensaje
MÓDULO 02

Operaciones Matemáticas

Ejercicios enfocados en la lógica de programación aplicada al cálculo numérico, resolución de operaciones aritméticas básicas (suma, resta, multiplicación, división) y obtención de promedios mediante scripts interactivos.

  • Suma
  • Resta
  • Multiplicación
  • División
  • Promedio
  • Operaciones Generales
MÓDULO 03

Condicionales y Lógica

Implementación de estructuras de control de flujo (como if-else y switch) para evaluar condiciones, resolver problemas de validación de datos (números positivos/negativos, mayoría de edad para votar) y toma de decisiones lógicas.

  • Condicional
  • Positivo o Negativo
  • Comparación
  • Estructura Switch
  • Votar
MÓDULO 04

Funciones

Exploración y práctica con bloques de código reutilizables. Incluye la creación de funciones declaradas, expresiones anónimas, funciones flecha (arrow functions), funciones recursivas, manejo de parámetros y retorno de resultados.

  • Función Declarada
  • Función Anónima
  • Función Flecha
  • Función Recursiva
  • Función con Retorno
  • Parámetros
  • Funciones y Eventos
MÓDULO 05

DOM e Interactividad

Prácticas avanzadas sobre el Modelo de Objetos del Documento (DOM). Comprende la selección de elementos por ID, clases, etiquetas y nombres, así como la manipulación dinámica de atributos, estilos, textos e inserción de imágenes en tiempo de ejecución.

  • DOM General
  • Agregar Imagen
  • Cambiar Color
  • Cambiar Texto
  • Obtener Botón
  • Obtener Elemento
  • Get ID
  • Get Name
  • Get Class Name
  • Get Tag Name
